PTQ 优化目标：局部重建误差为什么不够

B1 DRQ：接受一点校准误差，换取更低最坏方向误差

首次提交 2026-10-08；正文 v1。

完整题名：When Lower Reconstruction Loss Hurts: Distributionally Robust Refinement for Low-Bit LLM Quantization。

DRQ 从一个已有 weight-only PTQ 结果出发。它不改 bit width、group、scale 或 zero-point，只细化整数码。其问题是：同一个小校准集上的重建误差更小，为什么任务表现仍可能更差？

Δ 表示受限的方向能量增加。论文在该不确定集合上最小化最坏重建损失，并将内层问题化为最坏输入方向：

因此它惩罚的不只是平均方向误差，还包括校准统计覆盖不足的方向。I 项避免小特征值使问题无界。

求解过程估计当前最坏方向，按该方向提出整数码修改，再为候选重新估计最坏方向。若只固定一次 u，码改变后最危险方向可能也改变。

方法允许校准损失小幅增加，同时要求检查子集满足容差。全部操作离线完成，运行时格式不变。

边界：这是特定二阶矩不确定集合上的鲁棒目标，不是对任意分布漂移的保证。最坏目标更低，也不代表集合中每个具体分布的损失都更低。

与旧路线的关系：GPTQ 强调局部二阶误差补偿；QEP 强调上游输入失配；DRQ 强调校准外方向风险。它们解决不同问题。

B3 JARQ：网格与整数码应该交替联合拟合

首次提交 2026-09-29；最新读取 v2 更新于 10-02。正文 v2。

完整题名：JARQ: Joint Alternating Refinement for Quantization。

DRQ 固定网格，JARQ 则认为网格也可能尚未拟合好。整数码改变后，最佳 scale 会改变；相关输入还让不同 group 的尺度相互耦合。

尺度更新：固定整数码，把一个输出通道所有 group 的贡献组合成 B，联合解 s 的最小二乘。

独立 refit 每个 group，会漏掉 B^T B 的非对角耦合。

码更新：固定尺度，对每个 group 作 bounded Babai nearest-plane proposal。QR 三角回代允许同时修改一组码，突破单坐标更新的局部停点。只接受误差下降的候选。

边界：单调下降与有限终止定理依赖精确 scale solve 等条件。实际阻尼、浮点误差与最终 cast 需要单独检查；也不保证完整任务损失单调下降。

基础目标仍用同一个 X_tilde 比较原权重和量化权重。正文另说明可接 QEP 式修正目标；不要把基础 JARQ 自动描述成完整跨层误差修复。

B4 Align, Then Correct：低秩补偿也需要一阶项

首次提交 2026-10-06；正文 v1。

完整题名：Align, Then Correct: Training-Free Two-Stage Low-Rank Compensation for Extremely Quantized Large Language Models。

量化模型通常不在任务损失的驻点。只拟合量化残差的二阶项，可能漏掉当前模型仍然存在的一阶下降方向。

第一阶段：原模型输入 x，与量化模型输入 x_hat 分开。对 e = Wx-W_hat x_hat 做 Fisher 加权、rank-r 输出对齐。

这是输出端和输入端都加权的 reduced-rank regression。论文再收缩 L1，减少有限校准样本下的奇异值高估。

第二阶段：在已补偿模型上重测梯度和二阶矩。用 K-FAC 近似构造自然梯度方向，再把“旧 adapter 加自然梯度步”截断到原 rank。

这里写的是阻尼与步长细节之前的核心形式。正文对步长设置和信赖区间另有处理。

边界：“training-free”指没有迭代训练 adapter，不代表无 backward。它需要梯度统计、模型前向与 SVD。部署还增加低秩参数和支路计算，不属于零开销量化。

C1 CurveTQ：把曲率直接放进 trellis 分支代价

首次提交 2026-10-06；正文 v1。

完整题名：CurveTQ: Rotation-Free Trellis Quantization of LLM Weights via Curvature-Weighted Search。

trellis codec 通过有状态路径生成权重值。它可以提供高维组合表示，而不需要存储指数大的完整码本。许多既有路线先旋转权重，再做近欧氏路径搜索。

Viterbi 利用可加分支代价，不增加状态数，却会选择不同路径。曲率只影响编码，解码器无需读取 Hessian。

无旋转为何可行：原坐标中保留的曲率不均，被路径代价显式考虑；幅度与边缘分布由 factored scale field 和每矩阵 quantile table 处理。

block 边界：每个编码块允许独立起始状态，并把状态写入压缩流。它让路径适应上个块误差反馈留下的残差。

位数不能漏算：正文常用 64 权重一块、14 bit 初始状态，单独增加约 0.219 bpw。报告的“2 bit”主配置总量约 2.29 bpw，不是严格 2.00 bpw。

理论边界：块内完整曲率仍有非对角项；实际分支代价舍弃了其中部分耦合。因此 Viterbi 精确求解的是其可加代理，不是全层离散量化全局最优。

C3 ShamAN-Q：用双侧稠密曲率拟合 sub-1-bit 因子

首次提交 2026-09-29；正文 v1。

完整题名：ShamAN-Q: Shampoo Augmented NanoQuant for Sub-1-bit LLM Weights。

它沿用 NanoQuant 的低秩二值部署表示，但把对角重建几何换成稠密 Kronecker 曲率。

不显式构造巨大的 Fisher 矩阵，只保存两侧统计。论文通过 KL-Shampoo 风格拟合得到二阶几何。

加入该几何后，ADMM 的连续 U/V 更新变成双侧 Sylvester 方程，而不再只是单侧 normal equation。

α>0 让分母保持正值。固定大矩阵的谱分解可缓存，小 rank 侧更新仍有计算成本。离散投影和部署格式维持原方法的结构。

此外，它在部分量化模型上刷新统计，并在相同总 bits 下重分配 rank。不能把全部收益都归给 Sylvester solver。

证据边界：正文部分比较采用单次运行；低 PPL 收益不代表所有模型、所有零样本任务都显著更好。sub-1-bit 指每原矩阵元素的等效因子存储成本。

NVFP4 与旋转：格式、舍入和校准一起设计

D1 OSFP4：对角 smoothing 不能脱离 block scale 优化

首次提交 2026-10-06；正文 v1。

完整题名：OSFP4: Joint Optimization of Diagonal Smoothing and Block Scales for NVFP4 Quantization。

NVFP4 每 16 个 E2M1 元素共享 E4M3 block scale。传统整数 smoothing 准则不能直接迁移，因为浮点网格非均匀，scale 也有表示约束。

OSFP4 对每个投影 jointly 优化对角 A、weight block scales，以及校准目标中的 activation scales。

确定性量化损失不平滑。论文引入 multiplicative dither 作为离线分析和优化代理：

然后分别构造 RTN 与 SIC / GPTQ-style feedback 的矩阵乘积误差目标。不同舍入过程对应不同优化目标，不是先独立选 scale 再随意换 rounding。

离线先优化连续代理，随后搜索可导出的 E4M3 scale，执行确定性量化。推理 activation scale 按实际输入确定，校准中的 Γ_X 不直接作为每 token 静态尺度使用。

边界：代理误差分析包含噪声独立等建模假设，并忽略部分误差乘积项。推理时并不随机 dither。少数位置需要显式 diagonal scaling。

论文在测量负载上保留约 94–97% 的 vendor NVFP4 prefill throughput。这是对原生 NVFP4 路径的保留率，不是相对 BF16 的加速倍数。

D2 Schur Replay：评估 scale 时，重放它会触发的 GPTQ 更新

首次提交 2026-09-29；正文 v1。

完整题名：Replay the Curvature: Accurate and Scalable NVFP4 Quantization for Large Language Model Inference。

一组 16 个权重共享 scale。GPTQ 舍入前面一列后，会修改后面列。因此按组初始快照独立选 scale，不能反映该 scale 真正提交后的误差。

对每个候选 scale，Schur Replay 从同一入口状态重放组内 GPTQ recurrence，再评分实际产生的误差 δ_G。

G 为当前 group，F 为未量化的未来坐标。Schur complement 消去未来可连续补偿的部分，不把所有当前误差都视为不可逆。

候选还必须位于可导出的 E4M3 网格。每次 replay 使用独立工作状态，不能让后评估的候选继承前候选修改。

论文另提供大模型执行基础设施：active-layer residency、host / disk 激活分层、输出行并行与及时释放全精度层。

边界：Schur score 假定未来变量连续最优，而未来最终还会离散量化。因此不是最终离散损失的精确预测。

摘要的 15.17× / 23.14× 是 397B 模型的测得每层量化处理时间优势，不是在线生成速度。算法精度贡献与基础设施速度贡献需要分别讨论。

完整题名：ThinQuant: Scalable Rotation Learning for Weight and Activation Quantization of LLMs。

目标是压低校准激活旋转后的最大坐标：

ADMM 用 thin matrix updates 求解该问题。给定选中子集时的降维可以是精确的；选择子集替代全数据仍有近似误差。这两层不能混为一个无损降维结论。

生成与训练一致性：模型会走到哪些状态

E1 OnlineQAT：在学生自己生成的前缀上问老师

首次提交 2026-10-07；4 页 work-in-progress。正文 v1。

离线蒸馏常使用固定答案前缀。量化学生部署时却使用自己生成的 token。早期量化偏差会把后续状态带离固定数据分布。

OnlineQAT 先做 block-wise W2 / W3 初始化，随后采样学生回答，在相同前缀查询冻结全精度教师。

论文使用 sampled reverse-KL 信号。对学生采样的 token a_t：

E2 TRACE：训练与 rollout 都是 FP4，也可能数值不一致

首次提交 2026-10-06；正文 v1。

完整题名：TRACE: Rollout-Guided Quantization-Aware Training for FP4 Reinforcement Learning of MoE Language Models。

MoE RL 的训练执行路径与 rollout kernel 不同。接近量化边界的小差异，可能把两边舍入到相邻 E2M1 码字，放大 policy mismatch，甚至改变专家路由。

它直接对齐两条量化路径，而不是分别最小化各自相对 BF16 的误差。

精确记录每个 rollout 激活与 KV 的完整结果会造成巨大通信。TRACE 只保留部分深层的 mantissa / scale 信息，再结合当前训练值重建局部指导参考。

这不是从一个 mantissa bit 无损恢复整个 rollout codeword。正文附录明确区分“局部 guidance reference”与精确码值。

前向采用被指导的 FP4 值，梯度通过 STE；RL loss 仍使用 trajectory、旧 rollout log-prob 和优势。

边界：最高 5.4× 是 rollout 加速，不是完整 RL wall-clock 提升。缓存记录、I/O、训练计算与序列长度都应单独计入。

E3 AlignQuant：位宽分配的单元应该与 GPU tile 一致

首次提交 2026-10-05；正文 v1。

按单通道或更细粒度分位宽，可能跨过 kernel tile 边界，造成不规则执行。AlignQuant 用同一二维 weight tile 连接 allocation、packed storage 和 GEMM。

每 tile 在 W4 / W8 候选间选择；activation 为 A8。对候选替换产生的输出扰动，用任务梯度加权：

prefill 与 decode 统计先各自归一化，再取较大相对重要性。在等大小 tiles 下，给低分 tile 分 W4，其他留 W8，以满足固定权重存储预算。

关键区别：W4 载荷被保存为 4 bit，但运行 kernel 可展开为 INT8 乘法。它不是每个 W4 tile 都使用原生 INT4 GEMM，也不是每阶段存一套不同权重。

推理存储还包含每 tile scale 和位宽标签。论文选定同一 packed model，再由 phase-specialized kernels 使用。

E4 DQ：prefill 与 decode 可以用不同表示甚至不同权重

首次提交 2026-09-22；正文 v1。

完整题名：Disaggregated Quantization: Specializing LLM Prefill and Decode。

prefill 更偏计算，decode 经常更偏访存。相同格式不一定同时最优。

格式拆分：共享权重下，prefill 使用低精度 activation 与原生 FP4；decode 保留更高精度 activation，减少额外转换并保住生成质量。

完全拆分：另训 compute-native prefill 权重，与紧凑 weight-only decoder 一起优化。prefiller 生成 prompt KV，decoder 直接消费；缓存结构维持兼容。

冻结 decoder 的扩展：已有 GGUF 等 decoder 不动，只训练与其兼容的 prefiller。这不是无需训练就把任意两个 checkpoint 随意拼接。

代价是额外 checkpoint。ODP 尝试从 SSD 流式加载 prefiller，并用长 prompt 的计算摊销加载。短输入可能得不偿失；MoE 稀疏激活也可能让加载更难摊销。

与 AlignQuant 的区别：AlignQuant 共享一个 packed 权重表示，用两阶段统计决定 tile 位宽；DQ 允许阶段格式乃至权重本身分离。

F1 TaSQ：先把 VQ 的目标空间改好，再学码本

首次提交 2026-10-02；正文 v1。

完整题名：Tailoring the Quantization Space for 1-Bit KV Cache Compression。

TaSQ 对 pre-RoPE K 做 VQ。核心不是仅增大码本，而是 query-guided weighting、cross-head normalization 与 covariance-aware grouping。

在该加权空间做欧氏 VQ，相当于近似优化 query-sensitive 误差。对角近似丢弃了 query 方向间完整耦合，换来易部署的结构。

随后，每 token 跨 KV heads 共享一个 RMS scale，摊薄元数据。分组时完整 RoPE pair 作为原子，不随意拆散频率对。

该 determinant 指标来自高率 VQ 代理，不是对 1 bit regime 的精确最优公式。分层配对也不是整个 partition 问题的全局最优求解。

权重和 codebook 离线吸收部分变换。推理 kernel 融合 lookup、scale 恢复、pairwise RoPE 与内积，无需额外在线 dense rotation。

“1 bit”核验：正文主配置的 K index 为 10/8=1.25 bit。再加跨头 FP16 scale，H=8、d=128 时为 1.266 bit / K 元素；V 为 1.25 bit。

静态码本、高精度窗口和 padding 未计入上述 rate。因此不能把标题直接写成整 KV 严格 1.0 bit、零额外内存。

F2 LeapQuant：少量化几次递归状态，比每次修补更有效

首次提交 2026-09-29；正文 v1。

完整题名：LeapQuant: Efficient Linear Attention with Accurate Recurrent State Quantization。

Gated DeltaNet / Kimi Delta Attention 把历史压入固定大小状态矩阵。每 token 更新后重新量化，会把舍入误差反馈到后续所有更新。

LeapQuant 按窗口量化：窗口内保持起点低比特状态不变，用高精度小更新 buffer 计算读出，到边界才重建并重新量化。

上式是概念记法；u_t 仍由真实递归规则计算，不是独立外部输入。

它再用少量高精度 rank-one 项提取 dominant state structure。称这些 (k,u) 对为 Compensator Tokens，因为能复用 token 更新路径，而不是生成真实文本 token。

残差另外 smoothing。窗口长度决定重编码频率、buffer 大小与读出成本；不是窗口越长越好。

证据边界：部分大型模型只取 8 层做效率测量，不用于完整模型质量论证。报告约 2.05–3.70× kernel speedup 与 1.47× end-to-end speedup，不应混成一个指标。

与普通 KV 不同：这里的低比特状态在更新中反复反馈；普通 attention KV 多为写入后反复读取。递归误差稳定性因此更加关键。

F3 WUSH-KV：保留上一版，但不再把它当唯一新预印本

首次提交 2026-09-29；正文 v1。

它分别对 K/Q 与 V/O 双方统计构造可逆变换。一个 KV head 对应多个 query consumers，K 侧需要聚合这些消费者。

V 变换可折进投影；一般 K 变换放在 RoPE 后，保留在线成本。它强调乘积误差；TaSQ 更强调低位 VQ 的分组空间与 lookup 结构。
